                          QUICK START
================================================================================

1. START THE SERVER
   cd /home/code/kernel-studio
   npm run dev

2. OPEN IN BROWSER
   http://localhost:3001

3. EXPLORE
   - Click "Marcus Aurelius" to view a kernel
   - Click "Chat" to talk with a kernel
   - Click "Settings" to configure

4. CREATE A CONTRADICTION
   - Go to Kernel Details > Contradictions
   - Click "+ Add Tension"
   - Fill in Pole A and Pole B
   - Set scar valence (0-100%)
   - Click "Create Tension"

5. CHAT WITH A KERNEL
   - Click "Chat" in navigation
   - Select a kernel
   - Type a message
   - Click "Send"
