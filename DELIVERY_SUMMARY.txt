================================================================================
                          QUICK START GUIDE
================================================================================

1. START THE SERVER
   cd /home/code/kernel-studio
   npm run dev

2. OPEN IN BROWSER
   http://localhost:3001

3. EXPLORE FEATURES
   - Click on "Marcus Aurelius" to view kernel details
   - Click "Contradictions" tab to see value tensions
   - Click "+ Add Tension" to create a new contradiction
   - Click "Chat" to start a conversation
   - Click "Settings" to configure models and weights

4. CREATE A CONTRADICTION
   - Go to Kernel Details > Contradictions tab
   - Click "+ Add Tension"
   - Enter Pole A: "Power"
   - Enter Pole B: "Compassion"
   - Drag slider to 80%
   - Select "Reign" from Life Phase
   - Click "Create Tension"

5. CHAT WITH A KERNEL
   - Click "Chat" in top navigation
   - Select a kernel from the sidebar
   - Type a message
   - Click "Send"
   - Receive authentic kernel response
