### Teams
- `GET /api/teams` - List teams

## 🎓 KEY CONCEPTS

**Kernels**: Digital personas with biographical data and internal contradictions

**Contradictions**: Value tensions with opposing poles (Pole A & Pole B)

**Scar Valence**: Intensity of a contradiction (0-100%)

**Mask Theory**: Framework for authentic responses by balancing contradictions

**Life Phases**: Different periods in a kernel's life (e.g., "Reign", "Exile")

**Refusal Flag**: Indicates when a kernel refuses to engage with a contradiction

## 🆘 TROUBLESHOOTING

### Server Won't Start
```bash
# Check if port 3001 is in use
lsof -i :3001

# Kill process on port 3001
kill -9 <PID>

# Try again
npm run dev
```

### Database Connection Error
```bash
# Check if PostgreSQL is running
psql -h localhost -U postgres

# Create database if needed
createdb -h localhost kernel_studio

# Seed data
npm run seed
```

### API Not Responding
```bash
# Check server logs in terminal
# Look for error messages

# Restart server
npm run dev
```
